# 测速协议（Speed Measurement Protocol）

> 目的：让"跑了多快"这句话可复核、可对比、不被口径糊弄。

---

## 1. 为什么需要协议

同一个策略，四种问法得四个答案：

| 问法 | v2 `model_250` 的答案 |
|---|---|
| 平均前进速度 | **0.4572 m/s** |
| 单帧峰值（所有环境所有帧里最大） | **0.9335 m/s** |
| 单环境最优（某个环境跑得最好的那一帧） | **1.8246 m/s** |
| 回合奖励 | 16.8 分（**不是速度**） |

社区公开成绩常引用「峰值 2.07，瞬时 2.20」——属**瞬时读数**。若不声明口径就横向比，0.457 会被误读成"差 4.5 倍"。本仓同时报四个统计量，让读者自己判断。

---

## 2. 固定条件

| 项 | 值 | 原因 |
|---|---|---|
| 并行环境数 | **32** | 少于 16 时单帧噪声大；多于此无收益 |
| 步数 | **1200**（丢前 100 步） | 前 100 步含 reset 抖动与初始瞬态 |
| 控制频率 | 50 Hz（env 默认） | 与真机控制环一致 |
| 速度命令 | **锁死单一值**（1.6 或 2.6） | 训练是区间采样，评测必须定点 |
| 朝向命令 | 0（相对朝向） | 只测直行 |
| 随机种子 | env 默认（不固定） | 多环境统计本身抑制随机性；若需严格对照可固定 |
| 读取字段 | `robot.data.root_link_lin_vel_b` 的 x 分量 | 机体系前向速度，非世界系 |
| 统计对象 | 每环境每步的前向速度标量 | 见下 |

---

## 3. 四个统计量定义

设 $v_{e,t}$ 为环境 $e$ 在时刻 $t$ 的前向速度，$E=32$，$T=1100$（丢掉前 100 步）：

$$
\text{mean} = \frac{1}{ET}\sum_{e,t} v_{e,t}
\qquad
\text{median} = \operatorname{median}_{e,t}(v_{e,t})
$$

$$
\text{P95} = \text{第 95 百分位}\{v_{e,t}\}
\qquad
\text{peak\_frame} = \max_{e,t} v_{e,t}
$$

另有 `peak_env = max_e ( max_t v_{e,t} )`——先对每个环境取时间最大值，再跨环境取最大，等价于 `peak_frame`；本仓保留两者仅作交叉校验（实测相等或差 <1%）。

> **报结论时以 `mean` 为准**，`P95` 说明上限感，`peak_frame` 只作参考。任何只报峰值的做法都会高估 2 倍以上。

## 4. 复现命令

```bash
cd duck-rl
.venv/bin/python probe_sprint_speed.py \
  --ckpt logs/rsl_rl/velocity/<run>/model_250.pt \
  --task Mjlab-SprintV2-Flat-MicroDuck \
  --cmd 1.6 --steps 1200 --num-envs 32 \
  -o logs/speed.json
```

输出 JSON 字段：

```json
{
  "checkpoint": "model_250.pt",
  "task": "Mjlab-SprintV2-Flat-MicroDuck",
  "cmd_mps": 1.6,
  "steps": 1200,
  "num_envs": 32,
  "forward_speed_mean_mps": 0.4572,
  "forward_speed_median_mps": 0.4560,
  "forward_speed_p95_mps": 0.6988,
  "forward_speed_peak_frame_mps": 0.9335,
  "forward_speed_peak_env_mps": 1.8246
}
```

## 5. 已知局限

1. **仿真空转**：`root_link_lin_vel_b` 不含地面约束，打滑时读数会高估真实位移。本仓用 `slip_velocity_mean` 交叉检查（v2 末值 0.054，较 v1 的 0.092 更低，说明打滑不是主要高估源）。
2. **未换算机身位移**：若需"百米成绩"，应用 `base_pos` 差分再除时间，本仓未提供。
3. **单命令点**：1.6 m/s 是 v2 训练分布上沿，2.6 是分布外。两点不足以画"速度-命令"曲线，仅够证明上界受命令约束。
4. **一次测量**：未做多种子重复，标准差未知。建议后续每点 ≥3 次取均值。

## 6. 与公开成绩的口径对照

| 来源 | 口径 | 数值 |
|---|---|---:|
| 本仓 v2 `model_250` | 平均前向速度（32 env × 1100 步） | 0.457 m/s |
| 本仓 v2 `model_250` | 单帧峰值 | 0.934 m/s |
| 社区公开（4090D / 512 env / 13500 iter） | 峰值 | 2.07 m/s |
| 同上 | 瞬时读数 | 2.20 m/s |
| Hannes（公开参考） | 未声明 | 1.6 m/s |
| Max Sumrall（公开参考） | 未声明 | 1.88 m/s |

**本仓不主张跨行对比**。差 4.5 倍的原因（环境数、迭代数、奖励设计、是否用了不同 MJCF）未做定量拆解。
