# 开源生态选型：近一年（2025-11 ~ 2026-11）能真正跑起来的仓库

> 判定标准只有三条：**代码能拿到**、**在你手上的卡能训完**、**数据格式能互通**。
> 只看 star 不看显存门槛，是备赛期最常见的坑。

## 0. 一句话结论

| 结论 | 说明 |
|---|---|
| ✅ **主线选 LeRobot + ACT** | 数据格式是事实标准，ACT 在 50 条小样本上最稳，你的 16 GB 卡 2~4 小时能迭代一轮 |
| 🟡 **次线试 SmolVLA** | 有语言指令泛化能力，16 GB 勉强，属于"加分区"不是"保分区" |
| ❌ **pi0.5 / GR00T N1.7 只做推理展示，不做训练** | LoRA 要 22.5 GB、全量要 70 GB，你的卡进不去；GR00T 推理 16 GB 刚好卡线，可以当答辩演示 |
| ❌ **别自己从零写模仿学习** | 你不是来比谁的 loss 曲线好看的，评分表 75 分在场景操作 |

## 1. 硬件前提（决定一切）

本机可用算力：**RTX 4060 8 GB + RTX 5060 Ti 16 GB**（驱动 581.57）。

这一条直接砍掉大半个候选池——**任何"微调要 24 GB 以上"的方案都不是备选项**，别在赛前两周赌一张租来的 A100 的网络和排队。

## 2. 论文 → 代码 → 能否在你机器上完整训练

| 模型 / 论文 | 代码仓库 | 训练显存门槛 | 你的卡 | 判断 |
|---|---|---|---|---|
| **ACT**（ALOHA 低成本双臂模仿学习） | `huggingface/lerobot`（`--policy.type=act`） | 论文单卡 **11 GB**（RTX 2080 Ti 即可） | 5060 Ti 16 G ✅ | **主力**，2~4 h 跑一轮 |
| **Diffusion Policy** | `huggingface/lerobot`（`--policy.type=diffusion`） | 与 ACT 同量级，步数更多 | ✅ | 备选，比 ACT 慢 2~3 倍 |
| **VQ-BeT** | `huggingface/lerobot` | 同量级 | ✅ | 小样本抖动大，不优先 |
| **SmolVLA** | `huggingface/lerobot` | 官方参考单卡 A100 / 20k 步；社区 4090 可跑 | 🟡 16 G 紧张 | 语言泛化挑战项 |
| **π0 / π0.5（openpi）** | `Physical-Intelligence/openpi` | 推理 >8 GB；**LoRA >22.5 GB**；全量 >70 GB | ❌ | 只可能做推理 demo |
| **GR00T N1.7** | `NVIDIA/Isaac-GR00T` | 推理 ≥16 GB；微调 ≥40 GB 推荐；精简版（LLM 冻结）24 GB | ❌ 训练 / 🟡 推理 | 演示，不训练 |
| **OpenVLA / OpenVLA-OFT** | `openvla/openvla` | 推理 ~16 GB；微调需 A100 级 | ❌ 训练 | 同上 |

> openpi 官方明确写了："**已测 Ubuntu 22.04，不支持其他操作系统**"——你在 Windows 上连它的环境都装不顺，这一条本身就否掉了它作为备赛主力。

**"完整训练几天"的真实答案**：ACT 这类模型不是"训几天"的活儿，是"训几小时跑一轮、改三次数据再训"的活儿。真正吃时间的是**采数据**，不是训练。

| 数据量 | 模型 | 卡 | 预估时长（官方/社区公开数据折算，非本机实测） |
|---|---|---|---|
| 50 条 × 5 s | ACT | RTX 3060 8 G（官方记录） | ≈ 6 h |
| 50 条 × 5 s | ACT | 4090 / A100 | 2~3 h |
| 50 条 × 5 s | ACT | **5060 Ti 16 G** | **估 2~4 h** |
| 200 条 × 8 s | ACT | 5060 Ti 16 G | 估 8~14 h（过夜跑） |
| 50 条 × 5 s | Diffusion Policy | 5060 Ti 16 G | 估 4~6 h |
| 50 条 × 5 s | SmolVLA LoRA | 5060 Ti 16 G | 估 12~24 h，有 OOM 风险 |

## 3. 值得抄的仓库（按"能抄什么"排）

### 3.1 LeRobot —— 数据格式与训练脚手架（必装）

- GitHub `huggingface/lerobot`，约 **27.6k ★**，Apache-2.0，最近提交 2026-09，PyPI `lerobot 0.6.1`
- **抄它什么**：`LeRobotDataset` 格式（Parquet + MP4）、`lerobot-record` / `lerobot-train` / `lerobot-eval` 三条命令、`Robot` 接口约定
- **为什么关键**：数据格式一旦统一就很难迁移，你现在采的数据三年后还能用
- 注意：v0.6 起要 **Python 3.12+**，别用 3.10 环境硬装

### 3.2 XLeRobot —— 形态最像 A 赛道的开源机

- GitHub `Vector-Wangel/XLeRobot`，约 **5.4k ★**，硬件 3D 打印 + 市售件
- 形态：**双臂（2× SO-101）+ 轮式底盘（LeKiwi）+ 摄像头 + 托盘**，$660 量级，3~4 小时组装
- **抄它什么**：双臂移动平台的结构布局、托盘/货架式承载、Quest 3 VR 遥操作采数、MuJoCo 仿真
- 局限：单臂承重 600~1000 g、臂展约 40 cm，干不了重活——但**端饮品正好在能力边界内**

### 3.3 reBot-DevArm —— 硬件开放度最高，且 Gitee 有镜像

- GitHub `Seeed-Projects/reBot-DevArm`，约 **4.4k ★**；**Gitee 镜像 `gitee.com/seeed-projects/reBot-DevArm`**（国内拉取快）
- 硬件 CERN-OHL-W-2.0、软件 Apache-2.0；BOM 细到每颗螺丝
- **抄它什么**：官方 LeRobot 中文教程（采数→训练→部署）、GR00T N1.7 微调教程、`reBot-DevArm-Grasp`（YOLO/OBB + RGB-D 抓取 demo）
- 它的验证流程值得直接照搬：**Quest 3 遥操作采 40 条 → 打 LeRobot 包 → 微调 → 次日真机自主**

### 3.4 RealFactory-Ego-Data —— 数据质检流水线（Gitee 独有，直接能用）

- **`gitee.com/ok_vincey/RealFactory-Ego-Data`**（深圳明志数科开源，源自 3C 产线两年部署）
- 三个模块：加载可视化 / **质控过滤** / **转 LeRobot v2.1 格式**
- **抄它什么**：质控判据——**手部检测率 < 50% 的片段自动丢弃**；按时间窗标记"可用段"和"废段"。这正是我们 `bev/dataset.py` 里 `W_STATIC` / `E_GAP` 想做的事，它做得更狠

## 4. 建议的三步路线

```
第 1 步（1 天）  LeRobot 装上，用公开数据集（lerobot/aloha_mobile_cabinet）跑通 lerobot-train
                 → 目的：确认 CUDA / 环境 / 显存基线，不涉及你的机器人

第 2 步（2 天）  实现一个 Robot 适配类，接你的底盘+手臂+夹爪，用 lerobot-record 采 50 条
                 → 目的：打通"真机 → LeRobotDataset"这一跳，这是最容易被低估的一步

第 3 步（1 天）  lerobot-train --policy.type=act 训 2~4 h，lerobot-record 跑 10 次算成功率
                 → 目的：拿到第一个可量化数字，再决定要不要上 SmolVLA
```

## 5. 与本仓库的关系

本仓库**不重复造训练框架**，只做三件开源仓库不替你做的事：

1. 赛题**任务状态机**与**异常恢复**（`bev/task.py`）——LeRobot 不管这个
2. **官方 SDK 适配口**（`bev/adapters/vendor_sdk.py`）——比赛方的接口不是 LeRobot 接口
3. **零依赖采集与质检**（`bev/dataset.py`）——现场网络不可控，先把数据留下来，训练前再转 LeRobot

数据流向：

```
真机/仿真 ──► bev/dataset.py（JSONL + meta，零依赖）
                    │
                    ├─ 质检通过 ──► 转 LeRobotDataset ──► lerobot-train (ACT) ──► 真机回归
                    └─ 质检失败 ──► 回炉重采 / 补标
```
