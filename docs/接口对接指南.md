# 接口对接指南（官方 SDK 公布后照做）

> 目标：把官方 SDK 包成 `bev/interfaces.py` 的 5 个方法，任务层零改动。

---

## 一、5 个接口的语义（契约）

| 接口 | 方法 | 返回值语义 | 现场注意 |
|---|---|---|---|
| `Navigation` | `goto(waypoint, timeout_s)` | True=到达 | 超时要返回 False，不能抛异常卡死 |
| `Navigation` | `pose()` | `Pose(x, y, yaw)` | 单位统一（米/弧度） |
| `Arm` | `move_to(target, timeout_s)` | True=到位 | target 用命名位姿，别写死关节角 |
| `Gripper` | `open()` | 无 | 失败不抛异常，用 `is_holding()` 判断 |
| `Gripper` | `close()` | True=夹到 | **必须用真实反馈**（电流/位置/力） |
| `Gripper` | `is_holding()` | 当前是否夹持 | 释放后必须能读到 False |
| `Vision` | `detect(labels)` | `List[Detection]` | 坐标用像素；深度可选 |
| `Voice` | `say(text)` | 无 | 本地离线，禁止云端 |

## 二、适配步骤

### 1. 打开模板

`bev/adapters/vendor_sdk.py` 里已有 5 个骨架类，逐个填 TODO。

### 2. 导航

```python
class VendorNav:
    def goto(self, waypoint, timeout_s):
        return self.sdk.navigation.goto_named(waypoint, timeout=timeout_s)

    def pose(self):
        p = self.sdk.navigation.get_pose()
        return Pose(p.x, p.y, p.yaw)
```

### 3. 机械臂 + 夹爪

```python
class VendorGripper:
    def close(self):
        self.sdk.gripper.close()
        return self.sdk.gripper.current_ma() > THRESH   # 用电流阈值判夹到
```

> 夹爪反馈是整个任务里最关键的传感器：抓空、夹歪、掉落都靠它判断。

### 4. 视觉

```python
from bev.perception import YoloVision

class VendorVision:
    def __init__(self, sdk):
        self.v = YoloVision(frame_getter=sdk.camera.read, weights="bottle.pt")
    def detect(self, labels):
        return self.v.detect(labels)
```

### 5. 语音

```python
from bev.voice import SapiVoice

class VendorVoice:
    def __init__(self, sdk):
        self.v = SapiVoice()
    def say(self, text):
        self.v.say(text)
```

### 6. 组装

```python
io = build_robot_io(sdk)
task = BeverageTask(io, cfg, log, tray)
task.run()
```

## 三、现场标定流程（建议 20 分钟内完成）

1. **建图/定位**：让机器人跑一遍场地，确认 `standby / prep / guest` 三个点可达；
2. **记录位姿**：把三个点写成命名位姿，填进 SDK；
3. **抓取位姿**：手动把机械臂移到瓶子上方，记录 `prep_bottle`；
4. **托盘位姿**：记录 `tray`（放瓶）与 `level_tray`（调平）；
5. **桌面位姿**：记录 `guest_table`；
6. **夹爪阈值**：空夹 vs 夹瓶各测 10 次，定电流阈值；
7. **语音**：播一遍四句话，确认能听见。

## 四、联调顺序（别一上来就跑全程）

| 顺序 | 验证项 | 通过标准 |
|---|---|---|
| 1 | 语音 | 4 句都能播 |
| 2 | 导航单点 | `standby → prep → guest` 各 3 次都到 |
| 3 | 夹爪空夹 | `close()` 空夹返回 False |
| 4 | 单瓶抓放 | 抓到 1 瓶并放稳托盘 |
| 5 | 双瓶装盘 | 2 瓶都上盘，托盘不洒 |
| 6 | 端盘导航 | 倾角全程 < 阈值 |
| 7 | 全流程 | 2 瓶上桌 + 语音 |

## 五、常见坑

| 现象 | 原因 | 处理 |
|---|---|---|
| 导航“到了”但停偏 | 停靠点误差 | 加视觉二次对准或降低速度 |
| 夹爪 close 返回 True 但没夹到 | 用位置判断而非电流 | 换力/电流阈值 |
| 放瓶后 `is_holding()` 仍 True | 夹爪未完全张开 | 重复 open + 等待到位 |
| 端盘时倾角抖 | 加减速过猛 | 降速 + 加调平动作 |
| 语音被现场噪声盖住 | 音量/语速 | 提高音量、放慢语速、加重复 |
